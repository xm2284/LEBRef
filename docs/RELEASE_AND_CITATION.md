## DOI archive

For a citable software artifact, create a GitHub release and archive it through
Zenodo or an equivalent repository. After the DOI is available, add it to this
file and, if required by the journal, to the manuscript data-availability
statement.

## Large artifacts

Raw datasets, feature caches, checkpoints, and full local result directories are
not committed to Git. If the authors decide to distribute selected large
artifacts, attach them through GitHub Releases, Zenodo, Hugging Face, or another
controlled artifact host with SHA256 checksums.
